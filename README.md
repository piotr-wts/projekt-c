# projekt-c
Projekt przychodni lekarskiej w języku C.

Projekt ten napisaliśmy na potrzeby przedmiotu 'Podstawy programowania 2' jako projekt.
Aby uruchomić gotowy program, należy wejść do folderu /bin/Debug i uruchomić plik
'ProjektPrzychodni.exe'.
(Nie należy usuwać plików zawierających bazę danych, tj. plików tekstowych).
